Desarrollo Web

Este curso está diseñado para brindar a los estudiantes de Ingeniería Multimedia conocimientos y experiencia práctica en el desarrollo web *front-end*. A lo largo del programa, los estudiantes avanzarán desde los fundamentos de HTML, CSS y JavaScript hasta el uso avanzado de librerías y *frameworks* como React.js.

El curso combina teoría y práctica, incluyendo proyectos tanto individuales como en equipo, para asegurar que los estudiantes puedan aplicar lo aprendido en contextos del mundo real.

Esta tarjeta de llamada a la acción es un lugar excelente para destacar información importante o mostrar un eslogan ingenioso.
